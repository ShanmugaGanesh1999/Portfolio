# Claude Terminal UX Fixes — 3 Items

## 1. Fix the dead navigation commands (/projects, /about, /skills, /experience, /contact)

**Root cause (two-layer):**
- The auto-scroll effect fires after the user-entry block is pushed and snaps the viewport back to the bottom, cancelling the in-flight smooth scroll to the anchor.
- Even when scrolling works, these commands print nothing into the conversation — no visible output.

**Fix:**
- `scrollToAnchor`: disable auto-scroll pinning **before** the block push, scroll on the next animation frame (after the effect settles), and keep pinning off ~900ms.
- Every nav command now prints a `✻ → about` system entry (visible feedback, lands in the transcript).
- Fallback: if the anchor is somehow missing, print the section heading + a "run /clear to restore the welcome document" hint instead of failing silently.
- **Prefix matching**: unknown `/project` → suggests + runs `/projects`; `/contacts` → `/contact` (find the command whose name starts with the typed token). Kills the "typed the wrong plural, nothing happened" trap.

## 2. Project deep-dives as full-screen agent panes (Claude Code parallel-agent style) + /open picker

**Replace the boxed `⎿` embed** with a dedicated pane, like Claude Code's parallel-agent screens:

- **New `AgentPane` component** — full-screen layer inside the terminal (replaces scrollback+composer while open):
  - Header: `← esc` back button · `✳ explorer — market_data.md` agent-style title · status dot (● done) · language tag
  - Body: the existing full project viewer (`EditorContent` — HLD/LLD tabs, interactive diagrams, prep reader) at full size, scrollable
  - `Esc` or the back button returns to the terminal scrollback; the pane remembers its scroll position
- **`/open <project>`** → pushes a `● Read(market_data.md)` tool entry into the transcript AND opens the pane (replaces any open pane). Opening another project swaps panes — one pane at a time, like switching agent views.
- **`/open` with no argument → interactive picker** (the "don't make me type every character" fix): a panel-styled modal listing all 7 projects + both prep courses as numbered options — **type-to-filter box + ↑↓/Enter/click** — same pattern as the model picker. The slash menu's `/open` description updates to say "no argument opens the picker".
- Scrollback keeps the tool-entry trail (what was opened and when); the old embedded `⎿` box rendering is retired for `/open`.
- Esc priority becomes: pane → slash menu → interrupt.

## 3. Slash menu follows keyboard selection

- Add `scrollIntoView({ block: "nearest" })` on the `aria-selected` option whenever the selection index changes (effect keyed on `clampedMenuIdx` + menu matches).
- Also auto-scroll on hover-highlight, matching the model picker behavior.
