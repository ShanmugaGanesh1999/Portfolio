# Claude Code Shell — Implementation Plan

**Concept:** a `shellMode` toggle (**VS Code ⇄ Claude Code**) at the top of both shells. Same workspace engine underneath — tabs, hash routing, prep, projects, AI — so *everything keeps working*; Claude mode swaps the entire chrome for an authentic Claude Code CLI replica. VS Code remains first-visit default; the choice persists (`sg-shell`). Theming follows the existing dark/light toggle with Claude palettes.

## Authenticity spec (from CLI research)

- **Palette** — Light: ivory `#FAF9F5` bg, oat `#F0EEE6` surfaces, ink `#141413` text, terracotta `#D97757` accent, border `#D1CFC5`, success `#2C7A39`, error `#AB2B3F`. Dark: warm charcoal `#1F1E1D` bg, `#262624` surfaces, `#FAF9F5` text, same terracotta accent, success `#4EBA65`, error `#FF6B80`.
- **Typography** — Google Fonts (no npm deps): **Lora** (serif, ≈Tiempos) for display headings, **JetBrains Mono** for CLI body (claude shell only), **Space Grotesk** for small UI labels. VS Code shell keeps Space Mono untouched.
- **Spinner** — glyphs `· ✢ ✳ ✶ ✻ ✽` ping-ponging ~120ms; random gerund verbs ("Pondering…", "Sautéing…", "Vibing…", ~150 curated from the real list); line shows `✳ Ideating… (12s · ↓ 1.4k tokens)` while busy, past tense `✻ Sautéed for 24s` when done. Token counts are real (streamed chars ÷ 4).
- **Transcript grammar** — `❯` user echo, `⏺ Read(market_data.md)` tool rows (name ink, args muted), `⎿ Read 84 lines` indented results, `●` assistant text blocks (ReactMarkdown, claude-styled), collapsed italic thinking stub, `※` recaps.
- **Welcome banner** — rounded `╭─ Claude Code v3.0 ─┬─╮` box: greeting + model status line + **Tips for getting started** column with terracotta command tokens (`/open`, `/research`, `! ls`, `try "what did he build at Zoho?"`), `? for shortcuts` footer hint.
- **Permission prompts** — real interactive blocks with numbered options (`1. Yes  2. No, and tell Claude what to do differently (esc)`) for consequential actions (download resume, open mail client, schedule sync) — keyboard 1/2/3 + Esc, actually functional.
- **Agents** — panel below the prompt: bold `● main` + `◯ researcher  what did he build at zoho · ↓ 1.2k` rows using Claude's 8-color agent palette; mode line like `2 local agents running`; `/tasks` list with finished agents lingering 30s.

## Architecture

**State:** add `shellMode: 'vscode' | 'claude'` to the workspace reducer + `setShellMode` action; persisted to localStorage; effect sets `data-shell` on `<html>` (alongside `data-theme`). App renders `shellMode === 'claude' ? <ClaudeShell/> : <Layout/>` — both consume the same WorkspaceContext, so tabs/hash/deep-links/state survive mode switches. ClaudeShell is a lazy chunk (loads only when claude mode activates).

**New files (`src/shell/`):**
- `claude/ClaudeShell.jsx` — h-dvh column: ClaudeHeader / scrollback / AgentPanel / ClaudePrompt / thin footer (mode · cwd · agents · tokens)
- `claude/Scrollback.jsx` — session block renderer (capped ~150 blocks, pruned with fade), auto-scroll
- `claude/ClaudePrompt.jsx` — `❯` input (16px font → no iOS zoom), history ↑/↓, `/` opens filterable **slash menu** (name + description, arrows/enter/tab), `!` prefix = shell passthrough, plain text = natural language → existing RAG `chatService.chatQuery` **streaming** with thinking spinner, Esc interrupts (AbortController), `?` hint
- `claude/Spinner.jsx`, `claude/verbs.js`, `claude/AgentPanel.jsx`
- `claude/CliWelcome.jsx` — portfolio re-printed CLI-style from the same `portfolioData.js` (ASCII hero, stats as key-value lines, tech stack tree, career log, contact) with anchor targets for `/about` `/skills` etc.
- `claude/CliFileView.jsx` — bordered `market_data.md` file panel that embeds the existing project/prep viewers (GenericLLD, DiagramCanvas) — they auto-restyle because everything is token-driven; the tab also opens in the workspace (hash updates) so returning to VS Code shows it
- `claude/claudeCommands.js` — slash registry: `/help /open /projects /about /skills /experience /contact /resume /research <q> /tour /agents /tasks /model /theme /mode /clear /status /exit`
- `commands.js` — the shell command executor **extracted from Terminal.jsx** into a pure `executeCommand(cmd, ctx)` shared by the VS Code terminal and the Claude prompt (`!` passthrough) — one engine, two skins

**Modified:** `WorkspaceContext` + reducer (shellMode), `App.jsx` (shell switch + lazy), `index.html` (fonts + preconnect), `index.css` (`[data-shell="claude"]` token overrides for both themes + `--font-display` + utilities), `useTheme.jsx` (`useThemeColors` returns Claude hex maps for diagrams), `Header.jsx` (segmented **VS Code | Claude Code** switcher), `CommandPalette` (+ "Shell: Switch to Claude Code"), `Terminal.jsx` (refactor to shared executor + `claude` command).

**Agents (multiple, real):** `researcher` streams a genuine RAG answer; `explorer` opens project files; `/tour` runs three agents in parallel with staggered completion — visible concurrent spinners, live token counters (2Hz updates), results appended as `⎿` blocks. Model switcher `/model` reuses the existing chatService models.

## Performance & responsive

ClaudeShell lazy-loaded; only mounted blocks render; streaming via functional setState; ONE spinner interval total; scrollback pruning; fonts `display=swap`. Mobile-first: dvh + safe-area insets, slash menu capped at 40vh, blocks `break-words`, agent rows wrap, input 16px. All animations transform/opacity; reduced-motion respected (spinner becomes static glyph + text).

## QA (same rigor as the overhaul)

Full matrix: 320/375/390/768/1024/1440/1920 + landscape × dark/light × **both shells** × welcome/project/prep screens — zero overflow, zero console errors. Flow tests: slash menu navigation, natural-language streaming, Esc interrupt, agents parallel + token counts, permission prompts, deep links in claude mode, mode-switch round-trip preserving tabs, keyboard pass, build + lint (no new errors). Screenshots of both shells for visual sign-off.

## Out of scope

No changes to VS Code shell behavior beyond the header switcher/terminal/palette commands; no new npm dependencies; no content/data changes; no real Claude API (the RAG assistant remains the AI backend).
