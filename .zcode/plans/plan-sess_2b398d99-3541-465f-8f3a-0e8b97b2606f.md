# VS Code Portfolio Overhaul — Implementation Plan

**Goals:** authentic VS Code look/behavior, hardened app, smooth animations, effortless navigation, flawless mobile + any-resolution support, identical quality in dark and light themes.

## VS Code anatomy → implementation mapping

| VS Code element | Today | Plan |
|---|---|---|
| Activity bar (left icon rail) | Missing (floating FABs) | New `ActivityBar.jsx` — Explorer / Search / Prep / Copilot / Terminal icons + theme toggle at bottom; replaces all floating reopen-buttons |
| Explorer sidebar | Present | Kept, polished, single-mounted, aria-corrected |
| **Editor tab strip** | **Missing** (single `activeProject` swap, all state lost) | New `TabStrip.jsx` + workspace state; pinned non-closable **Welcome tab** holds portfolio content; projects/prep open as closable tabs with preserved state |
| Breadcrumbs | Missing | New `Breadcrumbs.jsx` (root > folder > file) |
| Command palette | Missing | New `CommandPalette.jsx` — fuzzy file/section/project/prep search + commands mode |
| Panel (Terminal/Output) | Missing | New bottom `Panel.jsx` with **interactive shell** + Output log |
| Status bar | Partial, desktop-only | Rebuilt: branch, errors/warnings, session timer, live Ln/Col from scroll, language mode, terminal/copilot toggles — visible on mobile too |
| Copilot chat (right panel) | Present | Kept as the Copilot panel; markdown renderer swapped to ReactMarkdown (kills XSS surface), better error handling |
| Keyboard shortcuts | None | Cmd/Ctrl+K, Cmd/Ctrl+Shift+P, Ctrl/Cmd+B, Ctrl/Cmd+J, Ctrl+`, Esc-stack |

## Architecture: workspace state (new `src/workspace/`)

- `workspaceReducer.js` — tabs[], activeTabId, explorerOpen, panelOpen/panelView, chatOpen, prep panel state, per-tab cache (scrollY, HLD/LLD choice), output log store (capped 200 events)
- `WorkspaceContext.jsx` — provider + `useWorkspace()`; **hash routing** (#/market_data, #/prep/dsa/README) so Back button works and tabs are deep-linkable/shareable
- Tab model: `{ id, kind: welcome|project|prep, title, icon, closable }`; only active tab mounted, state saved/restored from cache on switch
- `prepRoute.js` — single parse/encode util (dedupes App.jsx:33-37 / Layout.jsx:30-34)

## Phase 0 — Foundation & hardening (invisible, everything depends on it)

1. `useMediaQuery` hook (matchMedia + listener); replace every render-time `window.innerWidth` read (Layout, Sidebar, PrepTabBar, 8 diagram files, PrepPlatform)
2. Pointer-event resize (`useResizable*` + `ResizeHandle`): touch works, `setPointerCapture`, fix dead drag-to-collapse thresholds, `role=separator` + keyboard resize
3. Fix `MobilePrepBar` hooks-order crash risk (early return before hooks)
4. `useScrollSpy` stable deps; render Sidebar **once** (kill duplicate observers + timers); session timer moves to single interval
5. Accordion: `max-h-[2000px]` → `grid-rows 0fr/1fr` (no clip, smooth)
6. Theme FOUC: inline bootstrap script in `index.html` sets `data-theme` pre-paint; `<meta theme-color>` synced per theme
7. `prefers-reduced-motion` global guard
8. Security/cleanup: **remove hardcoded Google API key at chatService.js:17 (⚠️ you must revoke that key in Google Cloud Console)**; swap chat markdown from regex+`dangerouslySetInnerHTML` to ReactMarkdown (already a dependency — closes XSS hole, adds code fences/tables); friendly offline/API-key-missing chat errors
9. Make `ml-lead-scoring` reachable (add `ml_lead_scoring.md` NAV_ITEM); fix dead dynamic Tailwind classes (PrepPlatform, MobileNav, MobilePrepBar); remove dead code (`scrollbar-thin`, `xs:` class)
10. Mermaid parser: visible parse-warning + empty-state instead of silent partial diagrams; cache fetched prep markdown

## Phase 1 — Tab system + routing + breadcrumbs

- `TabStrip.jsx`: icons, active state, ×, middle-click close, neighbor activation, horizontal wheel-scroll, auto-scroll active into view, `role=tablist/tab`; pinned Welcome tab
- Sidebar/Experience/MobileNav links call `openTab()` (buttons, not anchor hacks — deletes both 50ms `setTimeout` scroll workarounds)
- Per-tab scroll + HLD/LLD restore; project components get `initialHldLld`/`onHldLldChange` props (temporary until Phase 5)
- `Breadcrumbs.jsx` under tab strip; hash URL sync + popstate

## Phase 2 — Activity bar + Command palette + Status bar

- ActivityBar (desktop): toggles explorer/prep panel/copilot/panel; opens palette; theme toggle; tooltips with shortcut hints
- CommandPalette: hand-rolled fuzzy scorer (no dep); files mode (Cmd/Ctrl+K) + commands mode (Cmd/Ctrl+Shift+P: Toggle Theme, Open Copilot, Toggle Terminal/Explorer, Close All Tabs, Download Resume, Email Me); arrows/Enter/Esc, focus trap, backdrop blur; mobile: search icon opens full-screen sheet
- StatusBar rebuild (token-based, both themes, mobile-compact): branch `master`, 0 errors/warnings, session timer | Ln/Col (live from editor scroll), Spaces: 2, UTF-8, per-tab language mode, terminal/copilot buttons

## Phase 3 — Terminal panel (interactive shell)

- Bottom `Panel.jsx`: TERMINAL | OUTPUT tabs, chevron collapse, resizable height (120px–60vh), slide-up animation, toggled via status bar/activity bar/Ctrl+`
- Terminal: prompt `shanmuga@sg-sys:~/portfolio$`, history (↑/↓), commands actually control the site: `help, ls, cd <section>, open <project|prep>, cat resume.pdf (download), cat contact.txt, whoami, skills, theme dark|light, neofetch, clear, exit, sudo hire-me` (mailto easter egg); bash-style "command not found"
- OutputLog: timestamped app events (tabs, theme, model used, commands)

## Phase 4 — Theme consistency + animation polish

- Token sweep: replace dark-only hexes/classes (`bg-[#1a1f2b]`, `text-white` hovers) in ~20 files with theme tokens; delete the brittle `[data-theme=light] !important` patch
- Motion tokens (`--dur-fast/base/slow`, `--ease-out-quad`): tab active transitions, panel slide, palette scale-in, drawer slide, folder accordion, chat message fade-slide; tabs animate open (fade + 8px rise) — transform/opacity only (GPU-friendly)
- Theme crossfade (transient class on `<html>`, 200ms); subtle once-only scroll-reveal for sections (reduced-motion gated)
- `h-screen` → `h-dvh` + safe-area insets for notched phones

## Phase 5 — Consolidation (approved)

- `GenericLLD.jsx`: the 6 identical 541-line LLD files → 1 component driven by the existing `*LLDData.js` contracts (~3,200 lines deleted)
- `DiagramCanvas.jsx`: 7 diagram components (incl. older-generation `ValidationDiagram`) → 1 parameterized canvas with `useId` marker ids (~2,300 lines deleted)
- `ProjectViewer.jsx`: shared skeleton (breadcrumb/title/HLD-LLD tabs/Section/CodeBlock/DiagramView); per-project files shrink to thin wrappers; per-tab state persistence becomes automatic
- Page-by-page migration with screenshot diffs; data files untouched

## QA / verification (after every phase)

- `npm run build` + `npm run lint` (zero new errors; reduce the 39 pre-existing as files are touched)
- Playwright matrix: 320/375/390/768/1024/1440/1920 + phone landscape × dark/light × screens (welcome, every project tab, prep, palette, terminal, chat, drawer)
- Keyboard-only pass (palette nav, tab strip, Esc stack, focus return/trap); theme side-by-side screenshot diff; rotate/resize across 768px with panels open; touch-drag resizers; reduced-motion emulation

## Risks & notes

- Consolidation is the riskiest phase → done last, incremental, screenshot-verified; data files are the single source of truth and don't change
- No new npm dependencies (ReactMarkdown already installed; fuzzy search + hash router hand-rolled)
- Cmd/Ctrl+K conflicts with some browser bars — preventDefault only while palette binding; mobile uses icons
- OpenRouter key is public-by-design once bundled — client rate limits kept; recommend rotating it and setting a spend cap on your OpenRouter account (separate from this work)

## Out of scope

No content/data changes, no new deps, no SSR/backend, no mermaid feature expansion (hardening only).
